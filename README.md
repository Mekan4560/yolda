# Yoʻlda

Межгородские попутчики по Узбекистану. Пассажир ищет поездку и бронирует место, водитель публикует рейс и подтверждает заявки.

Тестовая версия: веб-приложение (PWA), которое ставится на Android с иконкой. Хостинг — GitHub Pages, база — Supabase (бесплатный тариф).

> ⚠️ Только для тестов с ненастоящими данными. Перед запуском с реальными пользователями нужно решить вопрос с хранением персональных данных граждан Узбекистана (сервер в Узбекистане или подтверждение юриста).

## Что умеет

- Два языка: узбекский и русский (переключатель на экране входа и в профиле)
- При регистрации выбор: водитель или пассажир (роль можно сменить в профиле)
- Мастер-аккаунт: статистика, все пользователи и поездки, блокировка, отмена поездок
- Регистрация и вход (пока по email; SMS добавим перед запуском)
- Поиск поездок по области, району и дате
- Бронь 1–4 мест, отмена брони
- Водитель: публикация рейса, приём / отклонение заявок, отмена рейса
- Свободные места пересчитываются базой автоматически
- Телефоны видны только участникам подтверждённой поездки

## Запуск — 4 шага

### 1. Supabase: создать базу

1. supabase.com → **New project** → имя `yolda`, регион Frankfurt (или ближайший).
2. Откройте **SQL Editor → New query** и выполните по очереди [`supabase/001_schema.sql`](supabase/001_schema.sql) и [`supabase/002_roles_admin.sql`](supabase/002_roles_admin.sql). В конце второго файла — строка, которая делает ваш аккаунт мастер-аккаунтом.
3. Для тестов отключите подтверждение email: **Authentication → Sign In / Providers → Email → Confirm email** — выключить. Иначе после регистрации нужно подтверждать почту.

### 2. Вставить ключи

**Project Settings → API**: скопируйте **Project URL** и ключ **anon public** в файл [`config.js`](config.js):

```js
window.YOLDA_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJ..."
};
```

Ключ `anon` публичный, его можно хранить в коде. Ключ **`service_role` никогда не вставлять** в этот проект.

### 3. Включить GitHub Pages

Репозиторий → **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)` → **Save**.
Через 1–2 минуты приложение откроется по адресу `https://mekan4560.github.io/yolda/`.

### 4. Поставить на телефон

Откройте ссылку в Chrome на Android → меню ⋮ → **Добавить на главный экран**.

## Как проверить

1. Зарегистрируйтесь как водитель, опубликуйте рейс.
2. В другом браузере (или после выхода) зарегистрируйтесь как пассажир, найдите рейс, забронируйте.
3. Войдите водителем → «Safarlarim» → рейс → «Qabul qilish».
4. Пассажир увидит статус «Tasdiqlandi» и телефон водителя.

| `districts.js` | Области и районы (сверить с официальным справочником) |
| `config.js` | Ключи Supabase |
| `i18n.js` | Переводы: узбекский и русский |
| `supabase/001_schema.sql` | Таблицы, права доступа, автопересчёт мест |
| `supabase/002_roles_admin.sql` | Роли, мастер-аккаунт, блокировка |
| `manifest.webmanifest`, `sw.js`, `icon*` | Установка на телефон |
